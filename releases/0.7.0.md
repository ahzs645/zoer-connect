# Zoer Connect 0.7.0

- New authenticated, read-only `GET /theme-overrides?theme=<folder>`. The theme defaults to the active one, and the route needs push or pull permission. It lists the block theme's Site Editor copies (saved `wp_template` and `wp_template_part` posts, plus customized `wp_global_styles`) with their type, slug, title, modification date, matching theme file path, and whether that file exists. It returns no content, so it exposes no user data.
- Why it exists: these database copies win over the theme's files. A code-only push of a theme whose header, footer, templates or styles were edited in the Site Editor can look like it did nothing. WordPress Manager uses this route to warn before that push.
- `GET /status` reports the `themeOverrides` capability.
- No change to transfers, imports or stored data.
