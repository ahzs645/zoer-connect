# Zoer Connect 0.7.0

- New authenticated, read-only `GET /theme-overrides/<folder>` (also `GET /theme-overrides?theme=<folder>`; the path form passes gateways that only forward declared query keys, such as Zoer's endpoint gateway). The theme defaults to the active one, and the route needs push or pull permission. It lists the block theme's Site Editor copies (saved `wp_template` and `wp_template_part` posts, plus customized `wp_global_styles`) with their type, slug, title, modification date, matching theme file path, and whether that file exists. It returns no content, so it exposes no user data.
- Why it exists: these database copies win over the theme's files. A code-only push of a theme whose header, footer, templates or styles were edited in the Site Editor can look like it did nothing. WordPress Manager uses this route to warn before that push.
- `GET /status` reports the `themeOverrides` capability.
- No change to transfers, imports or stored data.

## Release status: awaiting owner approval, without integration qualification

This stable release would also publish 0.5.4 and 0.6.0, which were never released on their own.
Like 0.5.3, it is prepared for the owner's approval **without** a live hosting or updater
qualification. The `qualified` receipt pins the exact runtime files and the ZIP, which is identical
to the `v0.7.0-rc.2` prerelease asset (SHA-256 `32e11fff…e580b`). It is not evidence of a hosted
update test. Sites see the update in wp-admin; it installs automatically only where an
administrator turned on automatic updates. After updating from 0.5.x, a destination's import
setup must be confirmed again before its next import (0.5.4).

What was verified:

- `make test` (899 checks) as unprivileged `www-data` on Linux PHP 8.1 and 8.3, and the package
  tests (deterministic ZIP layout).
- On the DDEV test site `ddev-zoer-connect-040-destination` (2026-10-17, live Zoer): the 0.7.0
  ZIP was installed over 0.6.0 through Zoer's verified-ZIP install; `/status` reports 0.7.0 with
  the `themeOverrides` capability; `GET /theme-overrides/<theme>` answered through Zoer's endpoint
  gateway with no copies, then with one Site Editor footer copy, by name and date only.
- 0.6.0 publication identity and cache receipts: qualified on the same test site on 2026-10-16
  (WordPress Manager 0.11.0 notes).

Not verified: an update on real hosting through the WordPress updater, and imports into a hosted
destination after the 0.5.4 setup change.
