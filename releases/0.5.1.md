# Zoer Connect 0.5.1

Block exports now preserve empty files. Previously, a zero-byte file could stop
a hosted Pull with `Snapshot block seal incomplete.` because the empty snapshot
and digest sidecar had never been created. The fix creates both durable files
before advertising the authenticated zero-block checksum and resumes existing
export checkpoints without changing the connection key or file selection.

Small files up to 256 KiB are prepared together within 250 traversal entries,
4 MiB of file bytes and the existing four-second traversal budget. Larger files
retain their bounded copy and source-verification checkpoints. Batches keep the
same per-file block seals, source identity checks and private journal. If a
response is lost, the uncommitted snapshots are truncated and replayed from the
saved queue without skipped or duplicated files.

Source file exporters now match Zoer's portable hidden-file boundary. Unsupported
development caches, generator folders and potentially sensitive dotfiles such as
`.npmrc` are omitted; permitted packaged metadata, `.github` files and content
`.htaccess` files remain supported. This prevents vendor development files from
blocking an otherwise complete local copy without widening the importer.

Download batches stop before a checksum block that would exceed their remaining
byte budget. Mixing small files with block-sized files no longer produces a
partial block and a false `Snapshot block changed.` error; the next request
resumes on the original block boundary.

The regression test covers a reopened export checkpoint, a zero-byte manifest
entry, downloading the following file, checksums, identical retries, small-file
batch replay, and byte-budget checkpoint resumption. The full
PHP suite passed in the existing Linux PHP 8.1 test image as an unprivileged user;
the package layout and deterministic-build checks passed locally. GitHub CI
passed the full PHP 8.1–8.3 matrix and package checks (run 37143225066).

WP Migrate's supplied source was consulted for comparison: its full-site exporter
adds files, including empty files, to ZIP batches; its large-file chunker uses
bounded stream copies. This patch is an independent fix to Zoer's block snapshot
protocol and preserves its source verification and private staging.
