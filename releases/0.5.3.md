# Zoer Connect 0.5.3 candidate

This is an unreleased source candidate. Installed sites and the published stable
update remain 0.5.2. No release tag, update-feed metadata or hosting qualification
is provided by this change.

Clients that see `capabilities.compactImportResponses` may request
`?view=compact` on native import creation, status, steps and controls. Responses
retain exact source/destination binding, durable phase, progress counts, safe
errors, recovery refusal and bounded replacement samples without repeating
every artifact and upload offset. The ordinary detailed API and authoritative
`?view=upload` cursor remain unchanged. Compact identities are limited to 2,048
bytes; longer identities keep their exact value through the detailed API.

The compact view reduces transport bytes and per-artifact filesystem checks.
It does not change complete journal persistence, staged verification, backups,
request fencing, rollback preconditions or publication scheduling. Full journal
decoding and write costs still apply.

Temporary-file tests cover 100,000-artifact response bounds, escaped excerpts,
exact identities, detailed legacy responses, native capability/query selection,
idempotent completed finish, pause/resume, successful rollback and later-edit
refusal. Source/package metadata consistency and reproducible packaging are
checked separately. These fixtures are not a live-site update or hosting test.

Local verification passed the full `make test` suite as unprivileged `www-data`
on Linux PHP 8.3.35 in the cached official WordPress image, with networking
disabled, read-only source and temporary fixture storage. All six release-guard
tests, four update-manifest tests, reproducible ZIP/layout and version-consistency
checks passed. Development metadata and ZIP checksum validation passed without
a qualification receipt; stable publication remains gated on fresh integration
qualification.
