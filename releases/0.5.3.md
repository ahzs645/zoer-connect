# Zoer Connect 0.5.3

Clients that see `capabilities.compactImportResponses` may request
`?view=compact` on native import creation, status, steps and controls. Responses
retain exact source/destination binding, durable phase, progress counts, safe
errors, recovery refusal and bounded replacement samples without repeating
every artifact and upload offset. The ordinary detailed API and authoritative
`?view=upload` cursor remain unchanged. Compact identities are limited to 2,048
bytes; longer identities keep their exact value through the detailed API.

The compact view reduces transport bytes and per-artifact filesystem checks.
It does not change complete journal persistence, staged verification, backups,
request fencing, rollback preconditions or publication scheduling. Full journal
decoding and write costs still apply.

Export `source` now reports `originalUrls` with the source `siteurl` when it
differs from `home`, so imports into a destination replace URLs of WordPress
installed in a subdirectory, not only the home URL. Imports from a source with a
different table prefix no longer stage the source's `{prefix}user_roles` option
as an orphan; the destination's roles row is preserved as before.

## Release status: owner-approved without integration qualification

Unlike 0.5.1 and 0.5.2, this release was published at the owner's direction on
2026-10-09 **without** a fresh live hosting or updater qualification. The
`qualified` receipt for 0.5.3 records that approval and pins the exact source
files and the ZIP built by this repository's CI; it is not evidence of a
live-site update test. Automatic updates remain off unless a site's
administrator enables them.

What was verified:

- Temporary-file tests cover 100,000-artifact response bounds, escaped excerpts,
  exact identities, detailed legacy responses, native capability/query
  selection, idempotent completed finish, pause/resume, successful rollback and
  later-edit refusal. New tests cover `originalUrls` reporting
  (`tests/export-source.php`) and the dropped source-prefix roles row
  (`tests/prefix-roles.php`).
- The compact-response changes passed the full `make test` suite as
  unprivileged `www-data` on Linux PHP 8.3.35 in the official WordPress image.
- For the final source, every test except the Linux-only request-protection
  tests passed on macOS PHP 8.5; the full suite runs on Linux PHP 8.1, 8.2 and
  8.3 in CI before the package is built. Release-guard, update-manifest,
  reproducible ZIP/layout and version-consistency checks passed.
- No live WordPress site was updated to this build before publication.
