# Zoer Connect 0.9.1

## Import setup replaces a request fence copied from another site

A site restored from a hosting backup, migrated or cloned from another Zoer Connect site arrives
with that site's `wp-content/mu-plugins/000-zoer-connect-fence.php`. Its absolute paths belong to
the other installation, so Imports setup stopped with "Existing MU fence differs; inspect it before
replacement" and the site could not receive pushes until the file was deleted by hand.

- Setup (Enable shared-hosting migration, Install request fence, and the automatic setup when a
  connection key with Push is generated) now recognises an exact Zoer Connect fence, in its current
  or 0.5.x form and either cache mode, written for other paths, and installs this site's own.
- Any other file in that place is still refused and left alone, as are symlinks.
- A fence for this same WordPress folder with an earlier private storage folder is replaced only
  while that folder holds no paused transfer.
- The check lives in the new `includes/CopiedFence.php`, outside `WriteFence.php`, whose digest is
  part of each site's import readiness receipt: upgraded sites keep their readiness.

## Upgrading

Update from wp-admin when no transfer is running. A site that showed "Existing MU fence differs"
then needs Set up under Tools → Zoer Connect → Imports (or a new connection key with Push).

## Verified (2026-10-20)

- PHP suites (`make test` commands) in a Linux PHP 8.3 container as a non-root user, including
  `import-admin.php` and `request-drain.php`; the two ZIP suites (`export.php`,
  `export-modes.php`) on macOS PHP. New `tests/copied-fence.php` and import-admin cases: copied
  fences in every form are replaced, this site's own fence and foreign files are kept, and an
  earlier storage folder's paused transfer keeps its fence.
- The copied fence was found on a live Hostinger website restored from another site's backup,
  through Zoer Connect diagnostics; the fix has not been run on that site yet.
- Not verified: live hosting, the DDEV runtime and the native updater for this version.
