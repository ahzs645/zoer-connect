Zoer Connect 0.3.6 adds safe private-storage diagnostics and a first-time storage configuration form in Tools → Zoer Connect.

The connector status reports why storage is unavailable without exposing filesystem paths. WordPress administrators can inspect the current path and PHP restrictions, then validate a private location outside public roots. Existing configuration, transfers and installed import protection block relocation; the wp-config.php constant remains authoritative. The destination storage setting is preserved during imports and omitted from exported options.

Qualified on the disposable WordPress peer: existing PHP regression suites, new missing-parent/public-root/symlink/unwritable/missing-document-root diagnostic tests, and authenticated native HTTPS status, database snapshot export and cleanup. The earlier 0.3.5 file-publication/recovery implementation is unchanged. Deterministic package checks passed. No live-source storage change is implied by this release.

Install the attached plugin ZIP through WordPress Upload Plugin between transfers. Installing the plugin cannot override a host's filesystem restrictions; a writable private directory remains required. The matching Zoer application separately blocks unavailable-storage Pulls and implements local-copy creation from complete downloads.
