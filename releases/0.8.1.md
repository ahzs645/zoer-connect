# Zoer Connect 0.8.1

## Transfer storage and backup retention

- Activity → Transfers can measure retained storage on demand. Sizes include private
  artifact files and estimated private staging, backup and ledger table storage.
  Measurements are bounded, dated and cached; incomplete scans show a lower bound.
  Ordinary page loads do not scan the filesystem.
- Administrators can opt into daily cleanup of finished imports older than 1–365 days
  (default 30). The newest retained successful import is always protected. Cleanup
  preserves history and uses the import engine's existing lock, destination binding
  and resumable cleanup. Active/reused imports, invalid journals and missing completion
  dates prevent automatic deletion.
- Cleanup permanently removes eligible rollback data. The setting is off by default.
  Sites with WordPress cron disabled need an external cron runner.

- PHP 8.1, 8.2 and 8.3 regression suites passed in GitHub Actions for the implementation.
- Local PHP lint, retention/admin/import and updater checks passed. The full suite's
  Linux `/proc` fixture cannot run successfully on macOS.
- A development candidate was installed in place on overtheedge.unbc.ca. Imports and
  private storage remained ready; the three existing imports displayed measured sizes.
  The administrator-approved 30-day policy was saved and read back as enabled.

  A scheduled cleanup of eligible real backups, large-table cleanup and native updater
  qualification for this version remain unverified. This is not a stable qualification
  receipt; release candidates must remain labelled unqualified until qualification.
