# Zoer Connect 0.5.0 — stable

Qualified October 3, 2026 using the real Zoer cluster, task-owned DDEV sites and the authorized temporary Hostinger daycare review site. The exact source and deterministic ZIP are sealed in `releases/0.5.0.json`. [Detailed qualification](https://github.com/ahzs645/zoer/tree/main/docs/qualification/zoer-connect-050) includes sanitized checksum proofs. No production content was replaced.

## Changes

- Configurable incoming storage quota (16 GiB default; 1 MiB–64 GiB) with repeated free-space checks and a 64 MiB reserve. Hosted administrators configure it in Tools → Zoer Connect; `ZOER_CONNECT_TRANSFER_QUOTA_BYTES` overrides it. The matching Zoer backend and DDEV bridge use `ZOER_WORDPRESS_TRANSFER_QUOTA_BYTES`.
- New `largeTransfer` / `blockDigestExport` negotiation: bounded immutable source copy and verification, checksummed 256 KiB blocks, block-root manifests and downloads up to 4 MiB per request. Updated Zoer verifies the block root and computes normal whole-file SHA-256 for downloads/imports. Individual artifacts are limited to 4 GiB. Batch upload offsets now support that same ceiling.
- Bounded file publication, original backup and rollback process up to 32 blocks per phase/request. Legacy journals retain their existing recovery behavior. Existing destination quota settings survive database imports.
- Optional resumable hosted database export with typed keyset table/row checkpoints, bounded SQL parts and part checksums. It requires native Push and Pull, current request protection, InnoDB primary keys and explicit acknowledgement that earlier requests/background/external writers stopped. WordPress pauses until the database seals or the export is cancelled. Query reads use supported MySQL/MariaDB execution budgets; idle expiry releases the pause and prevents resuming an expired snapshot.
- WordPress Manager 0.5.6 offers the source-pause control for Pull, Backup and Export, with acknowledgement and table/row/part progress. The matching Zoer backend validates these choices and resumes downloads. Local consistent-snapshot exports keep their existing background worker, with configurable quota and ongoing disk checks instead of a fixed 2 GiB total.

## Qualification

Actual Zoer exported/downloaded a 2,203,978,458-byte set and pushed a 2,202,009,600-byte file over a 2,199,912,448-byte original. Review preserved the original; publish and rollback matched the full incoming/original SHA-256; finish and cleanup passed. Native source preparation and downloads at offsets above 2 GiB also passed.

A native source-pause SQL export survived an executing PHP-FPM worker's death and resumed to 344,869,407 bytes / 82 parts / 7,000 unsigned-64-bit-key rows, each exactly once. Part/root checksums passed and the source resumed. Hostinger passed a real 40 MiB Push/finish/rollback/cleanup, a verified maintenance-mode database Backup through Zoer's interface, quota persistence and missing/wrong-key 401 checks through canonical and rest_route URLs. Desktop/mobile acknowledgement gating and action reset passed. Native legacy no-options export and `/chunks` publication/recovery remained compatible.

Full PHP 8.1/8.2/8.3/8.4 suites, deterministic ZIP and release guards passed. Backend (42 tests), bridge (18 tests) and Manager (81 tests) passed their targeted verification/typechecks. Low disk space, corrupt blocks/parts, missing committed bytes, replay tails, cursor/schema rejection, cancellation and expiry have regression coverage.

## Upgrade and remaining bounds

API version remains 2. Clients that omit the new negotiation retain legacy semantics and bounds. **This release changes sealed fence code: repeat native request-protection setup before starting new imports or source-pause exports. Do not upgrade during an active transfer; existing authenticated recovery remains available.** Keep private journals on persisted storage outside the public root.

Default read-only hosted snapshots remain 256 MiB / up to 40 seconds in one transaction. Source-pause exports cannot promise consistency against external SQL writers that were not stopped, and SQL interruption is cooperative rather than a hard HTTP deadline. Parts target 4 MiB/about three seconds, individual SQL statements are limited to 16 MiB, and pauses expire after one idle hour / 24 hours maximum. Quotas are per transfer; simultaneous transfers and retained originals need additional free space. The separate selective-comparison and Updraft upload workflows retain their documented bounds. No unlimited migration or universal host compatibility is claimed.
