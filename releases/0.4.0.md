# Zoer Connect 0.4.0 — UNQUALIFIED — not released

Draft release notes. No qualification receipt (`0.4.0.json`) exists, so `scripts/check-release.py` and packaging stay blocked until integration qualification is complete and recorded.

## Changes

- API version 2: `/status` reports `apiVersion: 2` and per-feature capability flags. Clients that omit every new option get 0.3.14 behaviour, including identical idempotent export bindings.
- Pull database filters (`database` object): table suffix subset, post type inclusion list, exclude revisions, exclude spam comments, transients excluded by default. Dependent postmeta, comments, commentmeta and term relationships follow excluded parents inside the same consistent snapshot. Transient exclusions now escape LIKE wildcards; real transient rows are excluded exactly as before.
- Pull profile modes: `themesMode`/`pluginsMode` (`all`, `active`, `selected`, `except`) with item slugs, and `mediaSince` (UTC date). Export `source` reports `abspath` and exported `tables`.
- `GET /diagnostics` for Push or Pull keys: read-only site, PHP and database inventory with compatibility warnings and the pending plugin update.
- Import-side options, actions and summaries described in README "API version 2" (implemented in the parallel import workstream).
- Admin: Transfers list with backup cleanup for finished imports; editable export profiles with resource modes.
- Rollback of a file publication now also removes the directories that publication created (when empty), so rolling back a new theme or plugin no longer leaves an empty folder that WordPress reports as a broken theme.

## Qualification still required

- `make test` under PHP 8.1, 8.2 and 8.3 on Linux.
- Real MariaDB/MySQL: filtered snapshot SQL (subqueries, `ESCAPE '|'`) against a WordPress database with revisions, spam, attachments, link categories and transients; row counts compared with an unfiltered export; `/diagnostics` information_schema queries and `lower_case_table_names` on MariaDB 10.x/11.x and MySQL 8.
- Real WordPress: `active` modes with a child theme, single-file plugins, `mediaSince` against real upload mtimes, admin Transfers cleanup with the merged import engine, diagnostics plugin/drop-in detection, `update_plugins` transient.
- End-to-end Zoer Pull and Push with the new options, plus an old Zoer client against 0.4.0.
