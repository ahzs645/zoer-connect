# Zoer Connect 0.3.8

Add read-only destination file comparison for Zoer's selective Push screen, with Push authorization and no-store responses. Selected imports check the reviewed destination fingerprint before publication and again while capturing the original file for chunked backup. A changed destination is rejected and can be rolled back without replacing the later edit.

The updated Zoer app lets users filter by theme/plugin/file path, select individual files, skip identical files, and explicitly choose database replacement. Destination-only files and destination plugin/theme activation settings are retained in selective mode. Database records are replaced, not merged.

Comparison is bounded to 20 paths per call and 32 MiB per existing destination file. Protected, unreadable and larger destination files are excluded from selective comparison. Existing full-export chunked publication remains available for larger files. This release does not add database row merging or deletion synchronization.


Qualification: PHP unit/authentication/export/import/publication/recovery programs passed, including stale previews both before and after preparation. Readiness/process tests ran in a network-disabled isolated PHP container because synthetic readiness correctly rejects the real peer's unrelated workers. Backend Push/connection tests passed (9 tests, 65 assertions); scoped managed-proxy tests passed (6 tests, 57 assertions). Backend/frontend TypeScript and frontend production build passed.

The real Zoer browser compared 392 source theme files against `zoer-connect-transfer-peer`, initially skipping all identical files. After a harmless comment was added to the peer's CSS, it selected and pushed exactly one changed 611-byte file. Finish, HTTP 200, unchanged database/account/URL/activation checks, post-finish rollback and exact fixture restoration passed. The temporary test connection was removed and the peer's original credential restored. No customer WordPress site was modified. This qualifies the documented selective-file path, not unrestricted hosting compatibility or database row merges.
