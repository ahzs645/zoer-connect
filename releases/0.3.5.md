Zoer Connect 0.3.5 adds resumable file publication and rollback in 256 KiB blocks, removing the legacy 32 MiB per-file limit when paired with a block-capable Zoer backend.

- Incoming files and original destination files support up to 2 GiB; the managed-local export total remains 2 GiB.
- Interrupted copies, backup verification, retries and conflict-aware rollback retain durable progress. Legacy jobs keep their existing recovery path.
- Requires WordPress 6.5+, PHP 8.1+, and the matching Zoer backend capability. Hosted remote database Pull remains limited to one bounded request.

Qualification on the disposable WordPress peer passed native HTTPS upload and mixed database/file import, actual PHP-FPM worker termination during application and restoration, exact rollback verification and retained administrator identities. Large fixtures were 40–48 MiB; the 2 GiB boundary has not been stress-tested. A 37/41 MiB lifecycle also passed under a 16 MiB PHP memory limit. CI reruns the PHP suites and deterministic packaging checks; it does not rerun the private WordPress integration environment. The qualification receipt pins the runtime and ZIP that passed those checks.

Download `zoer-connect-0.3.5.zip` (not GitHub's source archive). In WordPress, use Plugins → Add New → Upload Plugin and replace the installed version. Keep an active migration's recovery available; update between migrations. This release does not include automatic WordPress update discovery and does not initiate a website migration.
